ထည့်သွင်းနည်း · How to install

  1. အပေါ်က ဒေါင်းလုဒ် ကို နှိပ်ပါ။ “File might be harmful” လို့ ပြရင် Download anyway ကို နှိပ်ပါ။ Tap Download. If Chrome says the file might be harmful, tap Download anyway.
  2. ဒေါင်းပြီးရင် အသိပေးချက် (notification) ကို နှိပ်ပါ၊ ဒါမှမဟုတ် Files → Downloads ထဲက app.apk ကို ဖွင့်ပါ။ Open the finished download, or find app.apk in Files → Downloads.
  3. “Install unknown apps” ခွင့်ပြုချက် တောင်းရင် Settings → Allow from this source ကို ဖွင့်ပြီး နောက်ပြန်လာပါ။ If the phone asks, go to Settings, turn on Allow from this source, and come back.
  4. Install ကို နှိပ်ပါ။ Play Protect က သတိပေးရင် More details → Install anyway ကို နှိပ်ပါ။ Xiaomi / Oppo / Vivo ဖုန်းတွေမှာ Continue ကို နှိပ်ပါ။ Tap Install. If Play Protect warns you, tap More details → Install anyway. On Xiaomi, Oppo and Vivo, tap Continue.
  5. ပြီးပါပြီ။ App ကို ဖွင့်ပါ။ Done. Open the app.

Play Store ကနေ မဟုတ်လို့ ဒီသတိပေးချက်တွေ ပေါ်တာပါ။ ဒီစာမျက်နှာက ဖိုင်ပဲ ဖြစ်ရပါမယ်။ These warnings appear because the app is not from the Play Store. Only install the file from this page.
